# 首版验收记录

验证日期：2026-09-28。

## 自动化

`npm run check` 运行 24 项测试并构建 Web / 微信两个客户端。

- 三种地图、所有敌军数量、相同种子复现、出生点间距和整图连通。
- 所属势力、相邻性、出兵整数、驻守下限、每轮一次行动。
- 战斗胜率、成功 / 失败伤亡、领地增长、跳过已淘汰势力。
- 建立 / 修改 / 删除运输路线、相邻友军校验、按快照结算、失守自动移除。
- 全灭敌人胜利、玩家最后一格失守失败、结果保存和再开战役。
- 损坏存档拒绝、AI 行动中恢复不重复出兵、新战役使旧 AI 任务失效。
- 24 组地图 / 种子组合，每局最多模拟 500 条 AI 指令，检查兵力、存档与回合不变量。
- 9 组桌面、手机、横屏与安全区尺寸，检查所有操作按钮在屏内且不重叠。
- 构建后的微信脚本在没有 `document` / `window` 的模拟环境内启动，注册触摸与生命周期并保存进度。

## 浏览器实际试玩

在内置 Chromium 浏览器中验证了：

- 新战役设置、进入地图、选取相邻目标、胜率预览和派兵。
- 一轮行动后禁止再次派兵，电脑依次行动，下一轮全境增长。
- 手机端选择两个友军格并建立运输路线；下一轮按设定执行。
- 刷新后保留兵力、轮次和运输路线。
- 1440×900、1280×720、390×844 的视觉布局与手机规则分页。
- 浏览器控制台无 error / warn。

本地验收截图输出到被 Git 忽略的 `artifacts/`，不作为运行时依赖。
