# 六边形战争 · HEXWAR

从一格领地开始，扩张、调兵、建立补给线。一个面向微信小游戏的单人回合制策略游戏，同时提供浏览器试玩版。

## 快速开始

需要 Node.js 20 或更高版本。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。选择地图规模和敌军数量后开始战役。开发服务器只监听本机，不会公开到局域网。

```sh
npm test       # 规则、存档、UI、微信适配测试
npm run build # 生成两个发布目录
npm run check # 测试 + 构建
```

构建输出：

- `dist/web/`：可部署到静态服务器的浏览器版本，无后端依赖。
- `dist/wechat/`：微信小游戏代码及资源。

## 导入微信开发者工具

1. 运行 `npm install` 和 `npm run build`。
2. 在微信开发者工具中新建 / 导入**小游戏**项目，选择本仓库根目录；根目录 `project.config.json` 已配置 `compileType: game` 和 `miniprogramRoot: dist/wechat/`。
3. 配置中的 `touristappid` 仅用于开发工具游客调试。真机预览、体验版和发布需要你自己的微信小游戏 AppID，请在开发者工具中填入。
4. 每次修改源码后重新运行 `npm run build`，再编译。

没有接入登录、云服务、广告、付费或数据分析。游戏进度只存于当前设备；微信和浏览器的存档各自独立。

微信客户端使用 `wx.createCanvas`、`wx.createImage`、触摸事件及本地存储；包含像素比、顶部胶囊区域和底部安全区适配。平台配置参考 [微信官方小游戏示例](https://github.com/wechat-miniprogram/minigame-demo)。实际真机表现仍须在微信开发者工具及 iOS / Android 微信内验收。

## 怎么玩

1. 选择小型（37 格）、中型（91 格）或大型（169 格）地图，设置 1–5 个电脑敌军。
2. 你是绿色的翡翠军团。每个势力以 1 块领地、18 兵开始，中立格随机有 1–6 兵。
3. 点击己方格子，再点击相邻目标。用 `−` / `+` 或 `1/4` / `1/2` / `全部` 调整出兵量，然后派遣。至少留下 1 兵驻守。
4. 每个势力每轮行动一次。点击结束回合后电脑依次行动，然后所有已占领地块各增加 1 兵。可以不行动，直接结束回合。
5. 选择两块相邻己方格子，开启「每轮自动运输」并建立路线；每个起点只能有一条，可随时修改或删除。建立路线不消耗行动次数。
6. 消灭所有敌方彩色格子即获胜；不需要占领所有中立格。丢失最后一块己方领地则失败。

拖动地图平移；使用 `+` / `−` 缩放，`◎` 复位。桌面可使用滚轮缩放、空格结束回合、Escape 关闭弹窗。再次点击已选为目标的友军格可将它切换为新的出发点。

战斗胜率为 `出兵² / (出兵² + 守军²)`；例如 10 对 5 的胜率为 80%。胜利时剩余 `max(1, 出兵 − ceil(守军 / 2))`；失败时出兵全部损失，守军剩余 `max(1, 守军 − floor(出兵 / 2))`。胜率预览不是胜利保证。

每轮结算顺序为：**各势力行动 → 所有占领地 +1 → 自动运输 → 新一轮**。运输保留 1 兵，不足时运走现有余量；新到的兵不能在同一轮连续中转。路线任一端失守后自动删除。单格兵力上限 9999。

## 项目结构

```text
src/core/         平台无关的确定性规则引擎、六边形坐标
src/ui/           共享 Canvas 界面、输入处理、战役控制
src/platform/     浏览器与微信生命周期 / 图片 / 存储 / 输入适配
assets/           原创 Logo
scripts/          本地开发服务器、双端构建
tests/            规则、回归、模拟对局及平台契约测试
docs/             方案评估、视觉设计说明
```

首版范围、设计取舍和未来联机方案见 [方案评估](docs/DESIGN.md)。Logo 及其生成说明见 [视觉设计](docs/BRAND.md)。

## 验证边界

自动化测试覆盖地图连通性与出生分布、战斗概率与伤亡、回合轮转、自动运输、胜负、存档校验和长局状态不变量；共享界面与微信适配还通过模拟平台测试。浏览器需进行真实点击、手机 / 桌面布局、刷新续战的人工验收。

微信 API 模拟测试不能替代微信开发者工具或真机测试。没有真实 AppID 或微信开发者工具时，不能声称已完成真机验收或微信发布。多人实时联机属于后续阶段，当前不提供房间或匹配入口。
